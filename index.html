Panduan HTTPS Lokal (Izin Kamera HP)

Mengapa Kamera HP Gagal Terbuka?

Browser HP (Chrome/Safari) secara ketat melarang aplikasi web mengakses kamera apabila tidak menggunakan protokol aman (**HTTPS**), kecuali dibuka di URL `localhost` Komputer itu sendiri.

1 Cara Tercepat Tanpa Install Apapun (Atur Chrome Flag di HP)

  1. Buka aplikasi **Google Chrome** di HP Anda.
  2. Ketik alamat chrome://flags pada address bar HP.
  3. Cari fitur bernama: "Insecure origins treated as secure".
  4. Ubah opsi menjadi Enabled.
  5. Masukkan IP Lokal Komputer & Port Anda (contoh: http://192.168.1.10:8000).
  6. Tekan tombol Relaunch di bagian bawah untuk me-restart Chrome HP.

2 Jalankan Server HTTPS Lokal Sederhana

Jalankan salah satu perintah berikut di terminal/command prompt pada folder tempat file HTML ini berada:

// Menggunakan NPX (Rekomendasi tanpa install):

npx http-server -S -C cert.pem -K key.pem

// Menggunakan Local SSL Proxy:

npx local-ssl-proxy --source 8001 --target 8000
